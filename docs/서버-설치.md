# 서버(Supabase) 설치 순서

사이트를 모든 선생님이 함께 쓰려면 서버가 필요합니다. 아래 순서를 한 번만 따라 하면 됩니다. 20분쯤 걸립니다.

> 설치 전에는 사이트가 체험용으로 동작합니다(올린 내용이 그 브라우저에만 저장됨).
> `js/config.js`의 두 칸을 채우는 순간 서버용으로 바뀝니다.

## 1. Supabase 프로젝트 만들기

1. <https://supabase.com> 에서 가입하고 **New project**를 누릅니다.
2. 이름은 자유(예: `dsms-tools`), Region은 **Northeast Asia (Seoul)** 을 고릅니다.
3. Database Password는 안전한 곳에 적어 둡니다(사이트에는 쓰이지 않습니다).

## 2. 데이터베이스 설치

1. 대시보드 왼쪽 **SQL Editor**를 엽니다.
2. 이 저장소의 [`supabase/setup.sql`](../supabase/setup.sql) 내용을 통째로 붙여 넣고 **Run**을 누릅니다.
3. "Success" 가 나오면 끝입니다. 나중에 이 파일이 바뀌면 같은 방법으로 다시 실행하면 됩니다(자료는 지워지지 않습니다).

## 3. 관리자 비밀번호와 가입 코드 정하기

SQL Editor에서 아래 한 줄을 **직접 고쳐서** 실행합니다.

```sql
select public.admin_setup('관리자 비밀번호(8자 이상)', '가입 코드(6자 이상)');
```

- **관리자 비밀번호**: 사이트 맨 아래 '관리자' 화면에 들어갈 때 씁니다.
- **가입 코드**: 선생님들이 첫 로그인 때 한 번 넣는 학교 공용 코드입니다.
- 두 값은 변환되어 저장되므로 나중에 다시 볼 수 없습니다. 잊었거나 바꾸려면 같은 줄을 새 값으로 다시 실행합니다.
- 이 두 값은 **어떤 파일에도 적지 않습니다.** 깃허브에 올라가면 누구나 보게 됩니다.

## 4. 사이트에 연결

1. 대시보드 **Project Settings > API** (또는 **API Keys**)에서 두 값을 복사합니다.
   - **Project URL** — `https://….supabase.co`
   - **Publishable key** — `sb_publishable_…` 로 시작
2. [`js/config.js`](../js/config.js)의 `supabaseUrl`, `supabaseKey`에 붙여 넣습니다.

이 두 값은 방문자 브라우저에 전달되는 공개 값이라 파일에 적어도 됩니다.
**`secret` 키나 `service_role` 키는 절대 적지 마세요.** 그 키가 있으면 누구든 모든 자료를 읽고 지울 수 있습니다.

## 5. 명단 등록하고 확인

1. 사이트 맨 아래 **관리자**로 들어가 3단계의 관리자 비밀번호를 넣습니다.
2. 선생님 명단을 붙여 넣고 **명단 저장**.
3. 본인 성함으로 로그인해 보고(가입 코드 → 내 비밀번호 정하기), 도구를 하나 올려 다른 컴퓨터에서도 보이는지 확인합니다.

## 알고 쓰는 것

- **무료 요금제는 일주일쯤 사용이 없으면 프로젝트가 멈춥니다.** 방학 뒤 사이트 목록이 뜨지 않으면 Supabase 대시보드에서 **Resume project**를 누르면 됩니다. 자료는 남아 있습니다.
- **비밀번호를 다섯 번 틀리면 5분 동안 잠깁니다**(선생님 로그인, 가입 코드, 관리자 모두).
- **좋아요는 로그인 없이 브라우저마다 한 번**입니다. 마음먹으면 수를 부풀릴 수 있습니다.
- **올라온 도구는 아직 격리 실행**이라, 점수·진행 상황을 기억하는 기능은 동작하지 않습니다(설계서 8-1절의 '별도 주소'는 배포 단계에서 붙입니다).

## 서버가 하는 일 (관리를 이어받는 분께)

- 표(table)는 모두 잠겨 있고, 사이트는 `supabase/setup.sql`에 정의된 함수만 부릅니다.
- 비밀번호·가입 코드·관리자 비밀번호는 bcrypt로 변환해 저장합니다. 로그인 표(token)도 변환해 보관합니다.
- 도구를 고치고 지우는 것은 올린 본인과 관리자만, 의견은 그 도구를 올린 본인만, 신고와 명단은 관리자만 볼 수 있습니다. 이 검사는 전부 서버 함수 안에서 합니다.
- 사이트 쪽 짝은 [`js/store-supabase.js`](../js/store-supabase.js)입니다.
